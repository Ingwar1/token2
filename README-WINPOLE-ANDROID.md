# Поле чудес — Android-порт

Личная Android-версия Windows-игры `PoleForWindows.exe` 2014 года.

## Версия 0.2

- исходный фон сцены, ведущий и все 16 кадров барабана извлекаются из оригинального EXE во время сборки;
- внутреннее разрешение оригинала 896×527 без растягивания пропорций;
- оригинальная база `Gamedata/base.dat` в Windows-1251;
- человек против двух ботов;
- барабан, очки, банкрот, ×2, ×4, плюс и призовые сектора;
- экранный русский алфавит и попытка назвать слово;
- альбомный полноэкранный режим Android.

APK собирается GitHub Actions из ветки `winpole-android-build`.
